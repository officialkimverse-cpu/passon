# Listing photos (optional)

Put your own furniture photos here to replace the default Unsplash images on the landing page.

| File name | Shown as |
|-----------|----------|
| `standing-desk.jpg` | Standing Desk (hero) |
| `office-chair.jpg` | Office Chair |
| `bed-frame.jpg` | Bed Frame (Queen) |
| `floor-lamp.jpg` | Floor Lamp |
| `microwave.jpg` | Microwave |
| `storage-shelf.jpg` | Storage Shelf |

Use **JPG or PNG**, roughly **800px wide** or larger. If a file is missing, the site uses a free stock photo automatically.

After adding files, commit and push:

```bash
git add public/images/listings/
git commit -m "Add listing photos"
git push origin main
```
